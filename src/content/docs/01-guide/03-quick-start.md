# 快速上手

## 从一条消息开始

1. 侧栏选择项目，点 `+` 新建会话
2. 底部输入框描述任务，回车发送
3. 流式区域按序出现：思考过程 → 工具调用 → 正文回复

每一轮（turn）由若干 span 组成——思考段、工具段、正文段各自独立折叠，展开的思考或工具列表会吸附在流顶部，长轮次内不丢参照。

## 输入框的三个入口

| 前缀 | 作用                                       |
| ---- | ------------------------------------------ |
| `@`  | 引用文件——弹出补全选择文件路径，注入上下文 |
| `/`  | 命令——执行内置或自定义斜杠命令             |
| `$`  | 技能——调用已安装的 agent skill             |

## 回复进行中你可以

- **排队**：继续输入的消息进入队列，当前轮结束后按序发出；队列可拖拽排序、可提升为 Steer
- **Steer**：输入指示立即注入当前生成流程，无需等待本轮结束
- **中断**：右下角圆形停止按钮立即取消当前轮

## 看懂标题栏

`分支 · 上下文用量 · 补全 token · 缓存命中 · 累计成本 · 速率 · 变更数`——做每件事的代价始终在你眼前。
