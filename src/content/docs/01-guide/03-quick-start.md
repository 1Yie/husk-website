# 快速上手

## 从一条消息开始

1. 侧栏选择一个项目，点 `+` 新建会话
2. 在底部输入框描述任务，回车发送
3. 流式区域按序出现：思考过程 → 工具调用 → 正文回复

一轮（turn）由若干块组成——思考、工具调用、正文各自独立折叠，展开后标题行会吸附在流顶部，长轮次里不丢参照。

## 输入框的三个前缀

| 前缀 | 作用                                           |
| ---- | ---------------------------------------------- |
| `@`  | 引用文件——弹出补全，选中后把文件内容注入上下文 |
| `/`  | 命令——执行内置或技能命令                       |
| `$`  | 技能——直接调用某个技能，可带参数               |

内置命令：

| 命令                        | 说明                                                  |
| --------------------------- | ----------------------------------------------------- |
| `/clear`                    | 清空会话历史                                          |
| `/compact`                  | 手动压缩上下文以释放 token                            |
| `/undo`                     | 回滚上一轮的文件修改                                  |
| `/model <provider>/<model>` | 切换模型                                              |
| `/diff`                     | 查看本轮改动的文件                                    |
| `/skills`                   | 列出工作区可用技能                                    |
| `/remember` `/forget`       | 写入或删除一条记忆                                    |
| `/blueprint`                | 查看架构蓝图索引（`check` / `graph` / `init` 子命令） |

## 一轮进行中你可以

- **排队**：继续输入的消息进入队列，本轮结束后按序发出；队列可拖拽排序，也可以提升为 Steer
- **Steer**：输入指示立即注入当前生成流程，不必等本轮结束
- **中断**：右下角停止按钮立即取消当前轮

## 看懂标题栏

`分支 · 上下文用量 · 缓存命中 · 累计成本 · 输出速率 · 变更数`——每一项都实时更新，成本和上下文占用始终在你眼前。详见[用量与成本](/docs/features/stats)。
