# 介绍

Husk 是一个运行于本地的 AI 编程智能体：Rust 编写的 agent 内核负责推理与执行，Tauri 桌面壳承载专为 agent 输出设计的流式界面。它把项目组织成工作区，让模型在其中读代码、改文件、跑命令，并把每一步——思考、工具调用、diff——都摆在流里给你看。

## 定位

网页聊天框适合问答，编程是持续、多分支、需要审查的工作。Husk 做成原生应用，是因为：

- **并行会话**——多个会话、多个项目同时推进，每个会话跑在独立的内核线程上，后台轮次不阻塞前台操作
- **本地工具**——文件读写、shell、git、测试运行器全部发生在你的工作目录，并经过权限裁决与沙箱
- **可审查**——工具调用、参数摘要、审批卡片、变更 diff 都在流里，随时展开回看
- **成本可见**——上下文占用、缓存命中、累计花费实时显示在标题栏

## 形态

Husk 提供两种形态，共享同一套内核：

| 形态     | 入口              | 场景                  |
| -------- | ----------------- | --------------------- |
| 桌面应用 | `app-tauri` crate | 日常编程协作，完整 UI |
| 无头 CLI | `app-cli` crate   | 脚本、CI、一次性任务  |

同一份配置、同一套工具、同一份会话持久化，两头通用。
