# 推理强度

输入框的紫色胶囊控制思考档位，共八级：关闭 → 最少 → 低 → 中 → 高 → 超高 → 极端 → 最大推理（max）。

## 档位如何到达模型

不同供应商的推理参数方言不同，内核统一做映射：

| 供应商方言  | 参数字段           |
| ----------- | ------------------ |
| OpenAI 兼容 | `reasoning_effort` |
| OpenRouter  | `reasoning`        |
| Qwen 系     | `enable_thinking`  |

`thinking_level_map` 可按供应商细调映射；供应商不支持推理时，高档位自动降级为最接近的能力。

## 思考过程的可视化

思考开启后流中出现「思考过程」行：点击展开完整推理轨迹（markdown 正文，不是日志）；展开状态下行本身吸附成胶囊浮在流顶部。超长轨迹会分段懒加载，展开不卡帧。
