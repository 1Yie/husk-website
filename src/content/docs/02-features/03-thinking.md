# 思考与推理强度

## 七个档位

思考强度决定模型在给出答案前投入多少推理：

| 档位      | 说明       |
| --------- | ---------- |
| `off`     | 关闭推理   |
| `minimal` | 最少       |
| `low`     | 低         |
| `medium`  | 中（默认） |
| `high`    | 高         |
| `xhigh`   | 很高       |
| `max`     | 最高       |

界面只列出当前模型真正支持的档位。切换模型后，如果原来的档位不在新模型的能力表里，会自动回退到一个受支持的值，而不是静默失效。

## 怎么映射到具体供应商

不同供应商的"推理强度"参数名与取值完全不同。Husk 在请求侧做一层翻译：

- 支持 `reasoning_effort` 的供应商 → 直接映射到该字段
- OpenRouter 一类 → 走它自己的 `reasoning` 参数
- Qwen 系 → 转成 `enable_thinking`
- 其余 → 按供应商能力表决定忽略或降级

如果某个模型需要特殊映射，可以在配置里用 `thinking_level_map` 逐档指定线路值：

```toml
[providers.deepseek.models.thinking_level_map]
high = "high"
max  = "high"
```

空字符串表示该档位在线上不发送任何参数。

## 界面上怎么看

思考过程以独立的块显示，标题行给出状态与耗时：

- 进行中显示「思考中 · 12s」，每秒更新
- 结束后变成「思考过程 · 12s」，耗时来自真实起止时间，切换会话后仍然正确
- 默认折叠，点开可读完整推理内容；很长的推理（超过约 1.6 万字符）会跳过展开动画，直接呈现

思考、工具调用、正文是三种不同的块，各自折叠，互不影响。
