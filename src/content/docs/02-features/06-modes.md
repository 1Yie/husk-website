# Agent 模式

输入框的机器人胶囊切换 agent 模式，模式决定内核给模型挂上哪套工具视图与系统提示：

| 模式 | 说明                                                 |
| ---- | ---------------------------------------------------- |
| 构建 | 全量工具——读写文件、跑命令、改代码，默认模式         |
| 计划 | 只读视图——只能看代码、搜索、列目录，输出方案不动文件 |
| 目标 | 目标驱动——围绕一个验收条件持续推进，中途自检         |

「计划」模式适合先让 agent 摸清方案再放开手干活；「目标」模式适合定义验收后放手长跑。

模式随时可切，切换通过 `UiCommand::SetAgentMode` 下发，下一轮的工
具视图即按新模式生成。
