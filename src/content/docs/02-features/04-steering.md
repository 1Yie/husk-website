# 排队与 Steer

轮次跑到一半，你往往会有新的补充。Husk 提供三种介入方式，按紧迫程度递增。

## 排队

直接发送消息即可。当前轮还在跑时，消息进入队列，本轮结束后按序发出。

- 队列内可拖拽排序
- 可以把某条队列消息提升为 Steer，立即注入
- 队列属于会话状态，切换会话再回来仍然在

## Steer

Steer 把指令立即注入正在生成的流程，不必等本轮结束。适合这些场景：

- 模型走偏了，立刻纠正方向
- 补充一个刚想到的约束
- 让模型改变正在进行的操作策略

注入的内容会在下一个回合边界被模型看到，不会打断正在传的 token 流。

## 中断

右下角停止按钮立即取消当前轮。已产生的内容保留在流里，可以接着发新消息。

如果只是想让模型换个做法，用 Steer；只有确实要放弃这一轮时才中断。

## 三者对比

| 方式  | 时机       | 效果                 |
| ----- | ---------- | -------------------- |
| 排队  | 本轮结束后 | 按顺序作为新消息发出 |
| Steer | 立即注入   | 本轮内模型即可看到   |
| 中断  | 立即       | 终止当前轮           |
