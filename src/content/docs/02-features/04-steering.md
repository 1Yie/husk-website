# 排队与 Steer

## 排队消息

回复进行中发送的消息进入队列，不打扰当前轮；当前轮结束后按序发出。队列里的消息可以拖拽重排，也可以提升为 Steer 立即生效。

## Steer

Steer 走另一条通道——`UiCommand::Steer` 绕过普通命令队列直达内核，立即注入当前生成流程：

- 方向跑偏时一句「别改那个文件，先看调用方」拉回正轨
- 补充中途才想起的约束，无需作废整轮

流式期间输入框占位符即「插入指示引导生成 (Steer)…」。

## 什么时候用哪个

| 场景                 | 用                 |
| -------------------- | ------------------ |
| 一连串独立需求       | 排队——它按序全做完 |
| 当前行为需要立刻纠正 | Steer——立即生效    |
| 想作废本轮重来       | 中断按钮，然后重发 |
