# 会话统计与成本

标题栏右侧一排实时统计，全部由内核 `Usage` 事件驱动：

| 项     | 内容                                 |
| ------ | ------------------------------------ |
| 分支   | 当前 git 分支与脏文件数              |
| 上下文 | 已用 token / 窗口上限 + 百分比饼图   |
| 补全   | 本轮 assistant 产出 token 数         |
| 缓存   | 命中缓存 / 未缓存 token 数           |
| 成本   | 本会话累计花费                       |
| 速率   | 当前生成速率 tok/s                   |
| 变更   | 本会话文件修改数，点击打开 diff 面板 |

## 上下文压缩

当历史接近 `compact_at` 阈值（上下文窗口的 70–90%，可配）时触发压缩：早期轮次折叠为摘要条目，工具输出按需裁剪，近期任务上下文保持完整。压缩期间流中显示动态压缩状态；抑制器保证压缩失败不会重试风暴。

## 流健康看门狗

内核与 UI 之间有流健康监控：长时间无 delta、异常断流会在流中提示「流可能中断」，可一键取消或等待恢复。
