# 用量与成本

## 标题栏上的数字

| 项         | 含义                               |
| ---------- | ---------------------------------- |
| 分支       | 当前工作区的 git 分支与改动状态    |
| 上下文用量 | 本次请求占用 / 模型上下文窗口      |
| 缓存命中   | 由供应商缓存命中的 prompt token 数 |
| 累计成本   | 按模型价格表累计的本次会话花费     |
| 输出速率   | 每秒生成 token 数                  |
| 变更数     | 本会话改动的文件数，点开可看 diff  |

速率在流式过程中先按字符数估算，收到真实 `completion_tokens` 后替换为精确值。计算时会剔除工具执行的停顿，因此反映的是模型真实的解码速度。

## 上下文压缩

上下文用到约 80% 时会自动压缩：较早的内容被压成一条 NOTE，上下文占用随之回落。界面上会出现一张压缩卡片，记录压缩前后的 token 数与移除的消息条数。

压缩检查点设在每个回合开始时，以及每两个工具轮之间——也就是说，不会在模型正说到一半时打断它。

需要立刻释放空间时，手动执行 `/compact`。压缩阈值可在「设置 → 通用」调整（0.7 / 0.8 / 0.9）。

## 成本计算

价格来自模型的 `cost` 配置，分输入、输出、缓存读取、缓存写入四项，支持分档计价。没有配置价格的模型只显示 token 数，不显示金额。

## 单轮耗时

每轮结束时，助手回复下方会标出这一轮的时间戳与总耗时。工具调用与思考的耗时则各自显示在对应的块上。
