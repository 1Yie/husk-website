# 项目与会话

侧栏两区：**会话**=跨项目最近列表（置顶优先，最多六条）；**项目**=按工作区展开的会话树。

## 会话的生命周期

每个会话由内核里一个独立的 `SessionActor` 掌管，跑在自己的线程上——这意味着：

- 切走不打断生成，回来时流按原样续上
- 后台运行的会话（parked handle）仍推进工具调用与审批等待
- 每轮结束时历史被快照落盘，崩溃重启后可恢复并清理续跑

## 会话操作

悬停行尾的 `···` 菜单：置顶、重命名、归档、删除。置顶会话固定在列表顶部并以书签标记。运行中的会话行内嵌动态状态图标。

## 变更面板

会话里每一处文件修改计入标题栏的变更计数。点击打开变更面板，逐文件查看 diff 与接受/回退。
