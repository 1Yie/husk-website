# 工具系统

每个工具由 `ToolRegistry` 注册为一份 `ToolSpec`：JSON schema、`readonly` 标记、`ToolClass` 分类、`network` 标记与执行体。执行上下文 `ToolCtx` 携带工作区根、沙箱后端、会话存储、记忆库、取消令牌、子代理孵化器和 UI 事件通道。

## 文件与代码

| 工具          | 别名          | 用途                  |
| ------------- | ------------- | --------------------- |
| `fs_read`     | `smart_read`  | 读文件内容            |
| `list_dir`    | —             | 探索目录层级          |
| `grep`        | `smart_grep`  | 进程内正则/字面量搜索 |
| `fs_patch`    | `fuzzy_patch` | 搜索替换式块编辑      |
| `apply_patch` | —             | 多文件结构化补丁      |
| `serena`      | —             | 符号级语义导航与编辑  |
| `todo`        | —             | 持久任务清单          |
| `remember`    | —             | 写入记忆条目          |

## 进程、批量与网络

| 工具            | 别名                | 用途                                      |
| --------------- | ------------------- | ----------------------------------------- |
| `bash`          | —                   | 沙箱内执行 shell                          |
| `test_runner`   | `smart_test_runner` | 跑测试/检查，输出过滤                     |
| `batch_execute` | —                   | 并行执行多个只读调用（仅 Observation 类） |
| `web_fetch`     | —                   | 抓取文档与参考资料；带 SSRF/限流防护      |

## 桌面交互

| 工具         | 用途                                             |
| ------------ | ------------------------------------------------ |
| `screenshot` | 截屏并把图像交给模型（只读 Observation 类）      |
| `computer`   | 键鼠驱动——点击、输入、滚动（Process 类，需审批） |

桌面后端为操作显示服务器刻意不走沙箱。

## 编排

`delegate` 孵化子代理处理有边界的子任务；`ask_question` 允许 agent 结构化地向你提问。
