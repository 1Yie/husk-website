# 记忆、技能与子代理

## 记忆

`MemoryStore` 保存跨会话的长期记忆（画像、偏好、项目约定）；`TurnDistiller` 在后台把每轮要点蒸馏入库。`remember` 工具让 agent 主动写入条目。

## 技能

技能是可复用的指令包（`$` 前缀调用），由 `SkillManager` 编目加载，注入系统提示的对应区块。技能可以把「怎么做某件事」封装成 agent 随时取用的手册。

## 子代理

`delegate` 工具孵化子 `Engine` 处理有边界的任务：

- 独立上下文与历史，继承父级的 provider、模型、工作区与沙箱
- 子代理的工具注册表不含 `delegate`——不能再套娃孵化
- 只读子任务可并行跑；子代理无人机交互能力，自主推进到底

父会话在流里看到 delegate 调用与结果，子代理内部展开过程不进主流。
